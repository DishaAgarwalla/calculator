A simple and responsive **Calculator Web App** built using **HTML, CSS, and JavaScript**.  
It performs basic arithmetic operations and provides a clean, user-friendly interface for quick calculations.

---

## 🚀 Features

- ➕ Addition, Subtraction, Multiplication, Division
- 🧠 Real-time input display
- 🧹 Clear (AC) functionality
- ⌫ Delete last entry support (if implemented)
- 📱 Fully responsive design
- ⚡ Fast and lightweight UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
